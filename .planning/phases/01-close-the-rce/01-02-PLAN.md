<objective>
Close the HTTP half of the RCE: the form layer joins the shared validation boundary, error copy becomes generic, and the view layer gets its kwargs-path tripwire.

**User story (continues Plan 01-01):** **As a** user of the public equilibria calculator, **I want to** have attacker payloads rejected at the HTTP boundary with clean, fixed error messages, **so that** my malformed submissions get understandable feedback and the server never evaluates smuggled code.

Plan 01-01 delivered the shared `calculations/security.py` boundary and rewired the engine. This plan: (1) deletes the form's duplicated formula regex and imports the shared one (SEC-05 drift elimination), (2) replaces both `JSONDecodeError` branches that echo parser exception text with fixed copy (D-06), (3) adds the shared-module drift-guard identity test and form error-copy assertions, (4) adds the missing view-layer kwargs-path tripwire (TEST-03), and (5) adds the 2-line `role="alert"` a11y hardening to the template while leaving the frozen success block untouched.

Purpose: The form is the load-bearing HTTP gate (D-04/D-05) — client K values are interpolated into the chempy string, so both the charset check and the finite-K check must draw from the shared module and must not leak parse internals to anonymous callers.

Output: rewired `forms.py`, drift-guard + error-copy tests, view-layer kwargs tripwire, a11y-hardened `equilibria.html`.
</objective>
