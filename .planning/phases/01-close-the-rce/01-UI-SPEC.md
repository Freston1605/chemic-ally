# Phase 1 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**Scope note:** This is a security-hardening phase, **not a redesign**. The user-visible surface is the equilibria calculator form (`templates/chemistry_calculators/calculator/equilibria.html`). The working tree already implements the form-layer validation errors and engine-boundary rejection; this contract locks the existing error-presentation patterns, defines the copy contract, and adds minimal accessibility hardening. Success-result display is contractually frozen (Section "Success Result — Unchanged").

## Spacing Scale

Bootstrap rem-based scale (1rem = 16px), granularity 0.25rem = 4px. **All NEW spacing values must be multiples of 4**; the scale sits on Bootstrap's 0.25rem grid. Frozen legacy values that fall outside the named token set are declared in the Exceptions table below — the UI is frozen this phase, so they are kept, not normalized.

| Token | Value | Usage (verified in codebase) |
|-------|-------|------|
| xs | 4px | Tag gaps, `ca-input-error` top margin, nav-link vertical padding (0.25rem) |
| sm | 8px | Element gaps (`gap-1`, `.ca-alert` gap 0.5rem) |
| md | 16px | Default element spacing: `mb-3`, result-card padding 1rem, button icon gap 0.5rem |
| lg | 24px | Section spacing: `mb-4`, `calculator-layout` grid gap 1.5rem, `py-4`, button horizontal padding (1.5rem) |
| xl | 32px | Layout gaps (no direct usage today — reserve for future) |
| 2xl | 48px | Major section breaks (primary button min-height 48px) |
| 3xl | 64px | Page-level spacing (no direct usage today — reserve) |

**Frozen legacy exceptions — outside the named token set (keep, do NOT normalize — the UI is frozen this phase):**

| Value | Token | Usage (verified in codebase) | Status |

## Typography

Active scale — **14px / 18px / 24px at 400/600** (the only sizes and weights new text in this phase may use):

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 18px (1.125rem) | 400 | 1.5 | Page text (`--bs-body-font-size`); `.ca-nav-brand` 1.125rem |
| Label | 14px (0.875rem) | 400 | 1.5 | Form labels (`--ca-text-muted`), table text (0.875rem), `small`, breadcrumbs |
| Heading | 24px (1.5rem) | 600 | 1.2 | `.ca-form-card h1`, `.ca-page-title` |

**Frozen legacy values — outside the active scale (keep, do NOT extend — the UI is frozen this phase):** the **13/14/15px cluster** is deliberate pre-existing sizing and must not be extended. **15px** (0.9375rem) — `.ca-alert` font-size (the only 15px outlier). **13px** (0.8rem) — `.ca-input-error` only, plus the 13px toggle-history label (0.8125rem). **~40px** (~2.5rem) — the pH result value in Bootstrap `display-4` at **weight 700** (the ONLY bold-700 usage besides the nav brand, `.ca-nav-brand` 700). These are deliberate existing accents, not part of the active scale.

Weights contract: **regular 400** (all body/label/error text) + **semibold 600** (headings, `.ca-breadcrumbs .current`, `.ca-tool-card h3`, "Calculation Failed" heading is Bootstrap `<strong>` = 700 — use `fw-semibold` class instead when editing that block, or keep `<strong>` as-is; do not introduce new 700-weight text). The only frozen 700-weight usages are the display-4 pH value and `.ca-nav-brand` (listed above) — not part of the two-weight contract.

GitHub-dark palette from `:root` tokens in `static/css/style.css`. Dark theme is the only theme (`data-bs-theme="dark"` hardcoded in `base.html`).

| Role | Value (token) | Usage |
|------|-------|-------|
| Dominant (60%) | `#0d1117` (`--ca-bg-page`) | Page background, nav, footer |
| Secondary (30%) | `#161b22` (`--ca-bg-card`) + `#21262d` (`--ca-bg-card-alt`) | `--ca-bg-card`: form card, alerts, suggestions, unit badge, tool cards. `--ca-bg-card-alt`: result card, input rows, history panel |
| Accent (10%) | `#14b8a6` (`--ca-accent`; hover `#2dd4bf`, muted `rgba(20,184,166,0.15)`) | See reserved list below |
| Destructive | `#f85149` (`--ca-danger`) | Destructive/error surfaces only (see reserved list) |
| Supporting (semantic) | `#3fb950` success, `#d29922` warning, `#e6edf3` text-primary, `#8b949e` text-muted, `#30363d` border | Not accent; must never be used where accent is reserved |

**Accent reserved for (exhaustive):** primary buttons (`.ca-btn-primary`, the "Add Reaction" `ca-btn-primary btn-sm`), all links + active nav indicator (`box-shadow: inset 0 -2px`), nav brand icon, input focus ring + border (`.ca-input-row:focus-within`), "Solution found" ✓ checkmark, copy/icon button hover, `--bs-link-color`.

**Destructive color reserved for (exhaustive):** `.ca-input-error` text, `.ca-alert-danger` left border, remove-reaction `×` button (`btn-outline-danger`), pH extreme badge (pH < 3 or > 11), `--bs-danger`.

**Do not add:** new accent usages, new hues, gradients, or light-mode variants in this phase.

## Copywriting Contract

All copy is **server-side constants**. Per D-06, error copy must NEVER interpolate the submitted reaction string or exception internals.

| Element | Copy |
|---------|------|
| Primary CTA | **Calculate** (existing `.ca-btn-success` in `_calculator_base.html` — unchanged; loading state swaps label to "Calculating…" with spinner) |
| Empty state (no reactions submitted) | "At least one reaction is required." (form auto-seeds 3 default rows — HCO₃⁻/H₂CO₃/H₂O system — so this fires only when the user deletes all rows and submits) |
| Per-reaction errors — format `Reaction {n}: {message}` (n = 1-based row index) | "Reactants cannot be empty." / "Products cannot be empty." / "K value cannot be empty." / "K value must be a number." / "K value must be a finite number." / "Reactants contain invalid characters." / "Products contain invalid characters." / "Missing '{field}' field." (field ∈ reactants, products, k_mode, k_value) / "Expected an object." / "k_mode must be 'pKa' or 'Ka'." |
| Hidden-field structural error | **"Reactions data could not be read."** (replaces working-tree `f"Invalid JSON: {e}"` — `str(e)` echoes attacker-controlled parse position; D-06 requires generic copy). Same for concentrations: **"Concentrations data could not be read."** (replaces `f"Invalid JSON: {e}"`). No test asserts the old message text (`assertIn("reactions", form.errors)` only) — safe to change. |
| Result-card failure (engine boundary) — heading | **"Calculation Failed"** (existing `<strong>` in `ca-alert-danger`) |
| Result-card failure — body | Validation rejection → **"Unsafe or malformed reaction string"** (the `ValueError` constant, surfaced via `result.error`). Any other solver exception → **"The equilibrium system could not be solved."** (replace `str(e)` in the `except` handler — never echo exception internals). Body is a server constant; the template renders `{{ result.error }}` unchanged. |
| Destructive action | Remove-reaction `×` button — **no confirmation dialog** (row is instantly re-addable via "+ Add Reaction"; low stakes). Keeps `aria-label="Remove this reaction"`. |

Rules: (1) every user-facing failure string above is a fixed literal; (2) the submitted reaction text must never appear in any error; (3) the string "Unsafe or malformed reaction string" lives in the shared `security.py` module so form and engine layers emit identical copy (SEC-05).

No new visual anchors are introduced this phase; these three are the frozen existing hierarchy.

## Success Result — Unchanged (Frozen Contract)

The `result.success` branch of `equilibria.html` (lines 141-215) is **frozen** — the executor must not modify it. Contract snapshot:

1. pH value in `display-4 fw-bold`, color banded: danger `--ca-danger` (pH < 3 or > 11, ⚠ glyph), warning `--ca-warning` (pH 6-8 outside, ⚠), success `--ca-success` (neutral, ✓). Verbal label ("Highly acidic" / "Acidic" / "Basic" / "Highly basic" / "Neutral") beneath.
2. "pH not applicable — no hydrogen ions in this system" when `ph is None`.
3. Solver info line: `Iterations: {n} | Function calls: {n} |` + ✓ "Solution found" (success) or ⚠ "Result may be approximate" (warning).
4. Species table: Species (`<code>`) / Equilibrium Conc. (M) (`floatformat:"6g"`) / log(Conc.) (scientific `slice:":8"`, 0 muted).
5. Copy button (`ca-btn-icon`) calling `copyToClipboard('#equilibria-result', this)` — shown only on success.
